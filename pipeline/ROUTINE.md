The API key is added to its requests by the environment's network secret (or read from API_FOOTBALL_KEY if that variable is set); never print, echo, log or write a key anywhere and never put one on a command line. 6. Bash: python3 -I A/pipeline/update.py --root R --today TODAY
It also downloads football-data.co.uk results and bookmaker odds itself when those hosts are reachable (if they are not, it reports that and continues). It verifies every fetched result against known results (a competition with wrong scores or unknown team names is left unchanged), updates Elo, builds the player bets from the API-Football data (or the topscorer tables when there is none), picks the superbet of the day, settles earlier predictions, player predictions and superbets against the results (R/state/track.json), rebuilds R/dist/streakscout.html and checks the page's model against Python. If the command exits non-zero, do not publish anywhere; finish with a short Dutch summary of the error.
